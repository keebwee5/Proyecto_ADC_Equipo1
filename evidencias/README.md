# Evidencias de funcionamiento

Esta carpeta debe completarse después de realizar la prueba física. Las instrucciones solicitan evidencias de:

- Programa compilado.
- REPL funcionando.
- Configuración del ADC.
- Divisor LDR + resistencia 10 kΩ conectado a 3V3, GP26 y GND.
- Demostración física.
- Funcionamiento en RP2040.
- Funcionamiento en RP2350.

No se incluyen evidencias simuladas ni fabricadas: deben corresponder al montaje real del equipo.

Registrar luz ambiente, LDR cubierta e iluminada con `luz regs` y `luz sdk` en cada tarjeta. Anotar ADC, voltaje, escala ADC y condiciones de iluminación. No exigir cifras predeterminadas.
